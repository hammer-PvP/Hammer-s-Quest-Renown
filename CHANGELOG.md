# Hammer's Quest & Renown — Release Notes

## 0.2.0

- Add manual rank benefit grants from General and Class Specific blocks with Item drag-and-drop, per-Character class eligibility and duplicate-grant protection.
- Add **Duplicate Quest**, creating an independent, unavailable definition without participant or payment history.
- Add a JSON Quest & Faction Library for transferring reusable definitions and referenced Item sources between Worlds; optional configuration import does not replace character histories.
- Add **Objective Tracking** in shared or per-Character mode, with personal progress visible in accessible Quest Journals.
- Add individual currency, Item quantity, and personal Renown overrides during Success Turn-In.
- Expand optional Failure Penalties to coin and matching Item forfeitures; Undo Failure can return recorded forfeitures.
- Add **Undo Success**, using inventory and currency checks and auditable compensating Renown transactions.
- Extend the supported D&D5e version range through 6.1.x without changing the module's independent Renown system.

## 0.1.11

- Add GM-confirmed deletion of disposable Quests, with safeguards for finalized outcomes and transactions.

## 0.1.10

- Place the three HQR Journal Directory controls in a dedicated row below Foundry's native buttons.
- Permit changing or clearing a Quest's Owner Faction without modifying its participants or recorded rewards.

## 0.1.9

- Add Quests without a required Owner Faction.
- Update Class Sources and Enabled Classes filtering while retaining previous preferences.
- Simplify Journal Directory access to Factions, Quest Manager, and Renown.
